# File Renamer

File Renamer is a Python utility that generates consistent filenames for a collection of files.

The application scans a list of filenames, applies a configurable naming pattern, previews the changes and creates a report without modifying the original files.

## Features

- Sequential renaming
- Custom prefixes
- Preview mode
- Rename report
- File statistics

## Example

Original

```
photo.png
IMG_4932.jpg
holiday.jpeg
```

Renamed

```
image_001.png
image_002.jpg
image_003.jpeg
```

Run

```bash
python main.py
```
